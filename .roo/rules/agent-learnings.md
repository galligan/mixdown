# Agent Learnings

## Critical Rules

1. ✅ ALWAYS read the most recent learnings from the [learnings.md](../../.agent/learnings.md) doc
2. ✅ ALWAYS put things you learn into into the learnings document in the appropriate [category](../../.cursor/rules/agent-learnings-categories.mdc)
3. ✅ ALWAYS update outdated learnings with the latest understanding
4. ✅ ALWAYS add sub-categories if it's helpful to do so, but don't go overboard
